# 🚧 Road Damage & Repair Management Portal

A web-based portal for reporting, tracking, and managing road damage and repair activities efficiently.

## 📌 Project Overview

The Road Damage & Repair Management Portal is a Flask-based web application that helps users report road damage and track the status of repair requests.

The project provides a simple interface for submitting complaints and managing road repair information through a database-driven backend.

## ✨ Features

- 📝 Report road damage
- 📋 Submit and manage repair requests
- 🔍 Track repair status
- 🗄️ Store road damage and repair information
- 🌐 Flask-based backend
- 📱 Responsive web interface
- 💾 SQLite database integration

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Tools:** Git, GitHub
